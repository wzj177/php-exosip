# GB28181 流媒体收流IP参数支持

## 概述

本文档描述 GB28181 流媒体点播和回放功能中，收流IP参数的实现和使用方法。

---

## 背景

在多服务器部署场景下，SIP信令网关和ZLMediaKit流媒体服务器可能部署在不同的服务器上。此时需要在发起点播/回放时，指定实际的收流服务器IP。

### 部署场景

#### 单服务器部署
```
┌────────────────────────┐
│  192.168.1.100         │
│  - SIP Gateway         │
│  - ZLMediaKit          │
└────────────────────────┘
```
**配置**: 使用默认的 `media_server_ip`

#### 多服务器部署
```
┌────────────────────────┐     ┌────────────────────────┐
│  192.168.1.100         │     │  10.0.0.50             │
│  - SIP Gateway         │────→│  - ZLMediaKit          │
│  - Web Backend         │     │  - 收流服务器          │
└────────────────────────┘     └────────────────────────┘
```
**配置**: 显式传递 `stream_ip = '10.0.0.50'`

## 实现方案

### 1. API层 (Gb28181Service)

#### 方法签名

```php
/**
 * 开始实时视频
 * 
 * @param string $deviceId 设备ID
 * @param string $channelId 通道ID
 * @param string|null $streamIp 收流IP (可选，默认使用配置的media_server_ip)
 * @return bool
 */
public function startLiveVideo(
    string $deviceId, 
    string $channelId, 
    ?string $streamIp = null
): bool;

/**
 * 开始录像回放
 * 
 * @param string $deviceId 设备ID
 * @param string $channelId 通道ID
 * @param string $startTime 开始时间
 * @param string $endTime 结束时间
 * @param string|null $streamIp 收流IP (可选)
 * @return bool
 */
public function startPlayback(
    string $deviceId,
    string $channelId,
    string $startTime,
    string $endTime,
    ?string $streamIp = null
): bool;
```

#### 实现代码

```php
// Gb28181Service.php
public function startLiveVideo(
    string $deviceId, 
    string $channelId, 
    ?string $streamIp = null
): bool {
    $params = $streamIp ? ['stream_ip' => $streamIp] : [];
    
    return $this->client->sendCommand(
        $deviceId,
        $channelId,
        'start_live_video',
        $params
    );
}
```

---

### 2. SDK层 (Gb28181Client)

#### 命令格式

```php
// 发送到Redis的命令格式
[
    'request_id' => 'req_12345',
    'action' => 'start_live_video',
    'device_id' => '34020000001320000001',
    'channel_id' => '34020000001310000001',
    'timestamp' => 1234567890,
    'params' => [
        'stream_ip' => '10.0.0.50'  // 可选
    ]
]
```

#### 实现代码

```php
// Gb28181Client.php
public function sendCommand(
    string $deviceId, 
    string $channelId, 
    string $action, 
    array $params = []
): bool {
    $command = [
        'request_id' => uniqid('req_'),
        'action' => $action,
        'device_id' => $deviceId,
        'channel_id' => $channelId ?: $deviceId,
        'timestamp' => time(),
        'params' => $params  // 包含 stream_ip
    ];
    
    return $this->redis->lPush('gb28181:commands', json_encode($command));
}
```

### 3. SIP网关层 (CommandDispatcher)

#### 关键实现

```php
// CommandDispatcher.php
private function handleStartLiveVideo(array $command): void
{
    $params = $command['params'];
    
    // 🎯 关键：优先使用 params['stream_ip']，否则使用默认配置
    $mediaServerIp = $params['stream_ip'] ?? $this->config['media_server_ip'];
    
    // 使用 $mediaServerIp 构建 SDP
    $sdp = $this->buildInviteSdp($channelId, $mediaServerIp, $port);
    
    // 发送 INVITE
    $this->sipServer->sendInvite($deviceUri, $sdp, $headers);
}
```

#### SDP 示例

**使用默认IP**:
```sdp
v=0
o=34020000002000000001 0 0 IN IP4 192.168.1.100
s=Play
c=IN IP4 192.168.1.100
t=0 0
m=video 30000 RTP/AVP 96
a=recvonly
y=0132000001
```

**使用自定义IP**:
```sdp
v=0
o=34020000002000000001 0 0 IN IP4 10.0.0.50
s=Play
c=IN IP4 10.0.0.50
t=0 0
m=video 30000 RTP/AVP 96
a=recvonly
y=0132000001
```

## 使用示例

### 场景1: 单服务器部署（默认配置）

```php
// 不传递 stream_ip，使用默认配置
$gb28181->startLiveVideo(
    '34020000001320000001',  // deviceId
    '34020000001310000001'   // channelId
);

// SIP网关将使用配置文件中的 media_server_ip
// 例如: 192.168.1.100
```

### 场景2: 多服务器部署（指定收流IP）

```php
// 显式指定 ZLM 服务器IP
$gb28181->startLiveVideo(
    '34020000001320000001',
    '34020000001310000001',
    '10.0.0.50'  // ZLM 服务器IP
);

// SIP网关将在SDP中使用 10.0.0.50
```

### 场景3: 录像回放

```php
// 回放也支持自定义收流IP
$gb28181->startPlayback(
    '34020000001320000001',
    '34020000001310000001',
    '2024-01-01T08:00:00',
    '2024-01-01T10:00:00',
    '10.0.0.50'  // 可选
);
```

### 场景4: 负载均衡

```php
// 根据负载动态选择 ZLM 节点
$zlmNodes = ['10.0.0.50', '10.0.0.51', '10.0.0.52'];
$selectedNode = selectLeastLoadedNode($zlmNodes);

$gb28181->startLiveVideo($deviceId, $channelId, $selectedNode);
```

```

│ 1. Web Backend (Laravel/Webman)                            │
│    - Gb28181Service::startLiveVideo($dev, $ch, $streamIp)  │
└─────────────────┬───────────────────────────────────────────┘
                  │
                  ↓ (传递 stream_ip)
┌─────────────────────────────────────────────────────────────┐
│ 2. PSipGateway SDK                                          │
│    - Gb28181Client::sendCommand(..., ['stream_ip' => ...]) │
└─────────────────┬───────────────────────────────────────────┘
                  │
                  ↓ (Redis LPUSH)
┌─────────────────────────────────────────────────────────────┐
│ 3. Redis Queue                                              │
│    - gb28181:commands                                       │
│    - {action: 'start_live_video', params: {stream_ip: ...}}│
└─────────────────┬───────────────────────────────────────────┘
                  │
                  ↓ (BRPOP)
┌─────────────────────────────────────────────────────────────┐
│ 4. SIP Gateway (php-exosip)                                 │
│    - CommandDispatcher::handleStartLiveVideo()              │
│    - 使用 params['stream_ip'] ?? config['media_server_ip'] │
└─────────────────┬───────────────────────────────────────────┘
                  │
                  ↓ (构建SDP，c=行使用收流IP)
┌─────────────────────────────────────────────────────────────┐
│ 5. SIP INVITE                                               │
│    - SDP: c=IN IP4 10.0.0.50                               │
│    - 设备将推流到 10.0.0.50:30000                          │
└─────────────────────────────────────────────────────────────┘
```

## 向后兼容性

### ✅ 完全兼容

- **不传 stream_ip**: 使用默认配置 `media_server_ip`
- **传 null**: 等同于不传，使用默认配置
- **传空字符串**: 等同于不传，使用默认配置
- **传具体IP**: 使用指定的IP

### 升级建议

1. **单服务器部署**: 无需修改代码，继续使用默认配置
2. **多服务器部署**: 
   - 方式1: 修改配置文件中的 `media_server_ip`
   - 方式2: 调用时显式传递 `stream_ip` 参数

## 常见问题

### Q1: stream_ip 和 media_server_ip 有什么区别？

**A**: 
- `media_server_ip`: SIP网关配置文件中的**默认**收流IP
- `stream_ip`: 调用API时**临时指定**的收流IP（可选）
- 优先级: `stream_ip` > `media_server_ip`

### Q2: 什么时候需要传递 stream_ip？

**A**: 
- ✅ ZLM 部署在单独的服务器
- ✅ 使用多个 ZLM 节点做负载均衡
- ✅ 不同设备使用不同的流媒体服务器
- ❌ SIP网关和ZLM在同一服务器（使用默认配置即可）

### Q3: stream_ip 可以是域名吗？

**A**: 不推荐。GB28181 SDP 标准要求使用 IP 地址，不支持域名。

### Q4: 如何实现负载均衡？

**A**: 
```php
// 示例：简单轮询
class ZlmLoadBalancer {
    private $nodes = ['10.0.0.50', '10.0.0.51', '10.0.0.52'];
    private $index = 0;
    
    public function getNextNode(): string {
        $node = $this->nodes[$this->index];
        $this->index = ($this->index + 1) % count($this->nodes);
        return $node;
    }
}

$balancer = new ZlmLoadBalancer();
$streamIp = $balancer->getNextNode();

$gb28181->startLiveVideo($deviceId, $channelId, $streamIp);
```

### Q5: 是否影响已有功能？

**A**: 不影响。所有修改都是**向后兼容**的：
- ✅ 不传 stream_ip 时，使用默认配置
- ✅ 已有代码无需修改
- ✅ 新代码可以选择性使用
