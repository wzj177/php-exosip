## 🎯 本次更新内容 (2026-01-12)

### 新增功能

1. **对焦控制 (Focus Control)**
   - `focus_near`: 对焦近 - 使镜头聚焦到近处物体
   - `focus_far`: 对焦远 - 使镜头聚焦到远处物体
   
2. **光圈控制 (Iris Control)**
   - `iris_open`: 光圈开大 - 增加进光量，画面变亮，景深变浅
   - `iris_close`: 光圈缩小 - 减少进光量，画面变暗，景深变深

## 📖 使用示例

### 1. 使用便捷方法 (推荐)

```php
use CoreW\Business\GB\Gb28181Service;

$service = new Gb28181Service($bfw);

$deviceId = '34020000001320000001';
$channelId = '34020000001320000001';

// 对焦控制
```

### 4. Laravel Controller 实现

```php
// app/Http/Controllers/Api/GB28181PtzController.php

public function focusControl(Request $request)
{
    $validated = $request->validate([
        'device_id' => 'required|string|size:20',
        'channel_id' => 'required|string|size:20',
        'action' => 'required|in:near,far',  // near 或 far
        'speed' => 'integer|min:1|max:255'
    ]);

    $service = app(Gb28181Service::class);
    
    $result = match($validated['action']) {
        'near' => $service->focusNear(
            $validated['device_id'],
            $validated['channel_id'],
            $validated['speed'] ?? 5
        ),
        'far' => $service->focusFar(
            $validated['device_id'],
            $validated['channel_id'],
            $validated['speed'] ?? 5
        )
    };

    return response()->json([
        'success' => $result,
        'message' => $result ? 'Focus command sent' : 'Failed to send command'
    ]);
}

public function irisControl(Request $request)
{
    $validated = $request->validate([
        'device_id' => 'required|string|size:20',
        'channel_id' => 'required|string|size:20',
        'action' => 'required|in:open,close',  // open 或 close
        'speed' => 'integer|min:1|max:255'
    ]);

    $service = app(Gb28181Service::class);
    
    $result = match($validated['action']) {
        'open' => $service->irisOpen(
            $validated['device_id'],
            $validated['channel_id'],
            $validated['speed'] ?? 5
        ),
        'close' => $service->irisClose(
            $validated['device_id'],
            $validated['channel_id'],
            $validated['speed'] ?? 5
        )
    };

    return response()->json([
        'success' => $result,
        'message' => $result ? 'Iris command sent' : 'Failed to send command'
    ]);
}
```

## 🔧 技术实现细节

### PTZ 命令格式 (GB/T 28181-2016)

```
格式: A5 0F 01 [指令码] [水平速度] [垂直速度] [速度组合] [校验码]
      ^  ^  ^   ^         ^           ^           ^          ^
      |  |  |   |         |           |           |          |
    固定头 |  |   |         |           |           |          校验和 % 256
          |  |   |         |           |           |
        固定值 |   |         |           |           高4位=变倍速度
              |   |         |           |           低4位=对焦/光圈速度
            固定值 |         |           |
                  |         |           垂直速度 (上下)
                  |         |
                  |         水平速度 (左右)
                  |
                  指令码 (位组合或单独命令)
```

### 指令码位定义

```
bit 7 (0x80): 保留
bit 6 (0x40): 保留
bit 5 (0x20): 变倍缩小 (zoom_out)
bit 4 (0x10): 变倍放大 (zoom_in)
bit 3 (0x08): 云台上移 (up)
bit 2 (0x04): 云台下移 (down)
bit 1 (0x02): 云台左移 (left)
bit 0 (0x01): 云台右移 (right)
```

### 单独命令码 (不使用位组合)

```
0x42: 对焦近 (focus_near)
0x41: 对焦远 (focus_far)
0x44: 光圈开大 (iris_open)
0x48: 光圈缩小 (iris_close)
0x81: 设置预置位 (preset_set)
0x82: 调用预置位 (preset_call)
0x83: 删除预置位 (preset_delete)
```

### 命令示例

```php
// 对焦近，速度5
// A5 0F 01 42 00 00 05 F1
// = 0xA5 + 0x0F + 0x01 + 0x42 + 0x00 + 0x00 + 0x05 = 0x1F1 % 0x100 = 0xF1

// 光圈开大，速度8
// A5 0F 01 44 00 00 08 FC
// = 0xA5 + 0x0F + 0x01 + 0x44 + 0x00 + 0x00 + 0x08 = 0x1FC % 0x100 = 0xFC

// 变倍放大 + 对焦近，速度各5
// A5 0F 01 10 00 00 55 14
//                   ^^
//                   ||____ 低4位: 对焦速度 = 5 (0x05)
//                   |_____ 高4位: 变倍速度 = 5 (0x50)
// = 0xA5 + 0x0F + 0x01 + 0x10 + 0x00 + 0x00 + 0x55 = 0x214 % 0x100 = 0x14
```

## ⚠️ 注意事项

### 1. 设备兼容性

- **并非所有设备都支持对焦和光圈控制**
- 需要设备硬件支持 (电动变焦镜头、电动光圈)
- 建议在接入前测试设备是否响应这些命令

### 2. 自动对焦 vs 手动对焦

- 这些命令用于**手动对焦控制**
- 如果设备处于自动对焦模式，手动对焦命令可能无效
- 某些设备需要先切换到手动模式

### 3. 光圈 vs 曝光补偿

- **光圈控制**: 物理调节光圈大小
- **曝光补偿**: 通过算法调整亮度
- 两者效果不同，根据需求选择

### 4. 前端交互建议

```
✅ 推荐:
- 按钮按下 (mousedown) → 发送 focus_near/iris_open
- 按钮松开 (mouseup) → 发送 stop
- 使用长按检测，避免误触

❌ 不推荐:
- 单次点击发送命令 (无法精确控制)
- 连续发送命令不停止 (设备可能过度调节)
```
