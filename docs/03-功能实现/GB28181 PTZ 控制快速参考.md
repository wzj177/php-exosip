# GB28181 PTZ 控制快速参考

## ✅ 支持的所有 PTZ 命令

| 命令 | 说明 | PHP 方法 | 命令码 |
|------|------|----------|--------|
| **方向** ||||
| `up` | 向上 | `$service->ptzControl($dev, $ch, 'up', 5)` | 0x08 |
| `down` | 向下 | `$service->ptzControl($dev, $ch, 'down', 5)` | 0x04 |
| `left` | 向左 | `$service->ptzControl($dev, $ch, 'left', 5)` | 0x02 |
| `right` | 向右 | `$service->ptzControl($dev, $ch, 'right', 5)` | 0x01 |
| **变倍** ||||
| `zoom_in` | 放大 | `$service->ptzControl($dev, $ch, 'zoom_in', 5)` | 0x10 |
| `zoom_out` | 缩小 | `$service->ptzControl($dev, $ch, 'zoom_out', 5)` | 0x20 |
| **对焦** ||||
| `focus_near` | 近焦 | `$service->focusNear($dev, $ch, 5)` | 0x42 |
| `focus_far` | 远焦 | `$service->focusFar($dev, $ch, 5)` | 0x41 |
| **光圈** ||||
| `iris_open` | 开大 | `$service->irisOpen($dev, $ch, 5)` | 0x44 |
| `iris_close` | 缩小 | `$service->irisClose($dev, $ch, 5)` | 0x48 |
| **预置位** ||||
| `preset_set` | 设置 | `$service->presetSet($dev, $ch, 5)` | 0x81 |
| `preset_call` | 调用 | `$service->presetCall($dev, $ch, 5)` | 0x82 |
| `preset_delete` | 删除 | `$service->presetDelete($dev, $ch, 5)` | 0x83 |
| **控制** ||||
| `stop` | 停止 | `$service->ptzStop($dev, $ch)` | 0x00 |

## 📝 新增功能 (2026-01-12)

### ✅ 对焦控制
```php
// 对焦近 (聚焦到近处物体)
$service->focusNear($deviceId, $channelId, 5);

// 对焦远 (聚焦到远处物体)
$service->focusFar($deviceId, $channelId, 5);
```

### ✅ 光圈控制
```php
// 光圈开大 (画面变亮，景深变浅)
$service->irisOpen($deviceId, $channelId, 5);

// 光圈缩小 (画面变暗，景深变深)
$service->irisClose($deviceId, $channelId, 5);
```

## 🎮 前端交互示例

```javascript
// 按钮控制 (推荐)

    sendPtzCommand('focus_near', 5);

```

## ⚠️ 设备兼容性说明

| 功能 | 硬件要求 | 兼容性 |
|------|---------|--------|
| 方向控制 | 电动云台 | 高 (几乎所有云台摄像头) |
| 变倍 | 电动变焦镜头 | 中 (中高端摄像头) |
| **对焦** | **电动对焦环** | **中 (需要确认设备支持)** |
| **光圈** | **电动光圈** | **低 (高端摄像头才有)** |
| 预置位 | 云台支持 | 高 (大部分云台摄像头) |

## 📞 如何决定是否接入

### ✅ 建议接入的情况
- 摄像头有电动变焦和对焦功能
- 需要远程精确调整画面
- 复杂光线环境需要手动调光圈

### ⏭️ 可以不接入的情况
- 固定焦距摄像头
- 自动对焦摄像头 (自动模式下手动命令无效)
- 自动光圈摄像头
- 低端摄像头 (可能不支持这些命令)

### 测试方法
```bash
# 先测试你的一台摄像头
php test_ptz_focus_iris.php

# 如果设备响应正常 → 接入
# 如果设备无响应 → 不接入 (不影响其他功能)
```
