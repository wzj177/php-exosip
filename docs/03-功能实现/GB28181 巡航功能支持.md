# GB28181 巡航功能支持

> GB28181-2016/2022 摄像头巡航控制功能的完整实现和使用指南

---

## 📋 功能概述

巡航（Cruise）是GB28181协议中定义的摄像头自动巡检功能，允许摄像头按预设路径在多个预置位之间循环移动，实现无人值守的自动监控。

### 🔄 工作原理
```
1. 预置位设置  → 手动定位到关键点并保存
2. 巡航路径配置 → 将预置位加入巡航组  
3. 巡航参数设置 → 设置移动速度和停留时间
4. 启动巡航   → 摄像头自动在预置位间循环
```

### ✅ 国标支持确认
- **GB/T 28181-2016**: ✅ 支持基础巡航指令
- **GB/T 28181-2022**: ✅ 增强巡航功能，新增巡航轨迹查询等
- **厂商兼容性**: ✅ 主流厂商基本都支持（海康、大华、宇视等）

## 🔧 命令格式

### PTZ 巡航命令格式
```
A5 0F 01 [指令码] [巡航组号] [参数/预置位号] [高4位参数] [校验码]
```

| 字节位置 | 值 | 含义 |
|---------|-----|------|
| 字节1 | A5 | 固定起始标识 |
| 字节2 | 0F | 固定组合码 |
| 字节3 | 01 | 固定地址 |
| 字节4 | 指令码 | 巡航操作类型 |
| 字节5 | 组号 | 巡航组编号 (0-255) |
| 字节6 | 参数 | 预置位号或参数低8位 |
| 字节7 | 参数 | 参数高4位或0x00 |
| 字节8 | 校验码 | 前7字节和的模256 |

### 指令码定义

| 指令码 | 功能 | 字节5 | 字节6 | 字节7 | 说明 |
|-------|------|-------|-------|-------|------|
| 0x84 | 添加巡航点 | 巡航组号 | 预置位编号 | 0x00 | 将预置位加入巡航路径 |
| 0x85 | 删除巡航点 | 巡航组号 | 预置位编号 | 0x00 | 从巡航路径移除预置位 |
| 0x86 | 设置巡航速度 | 巡航组号 | 速度低8位 | 速度高4位 | 移动速度 1-4095 |
| 0x87 | 设置巡航时间 | 巡航组号 | 时间低8位 | 时间高4位 | 停留时间 1-4095秒 |
| 0x88 | 开始巡航 | 巡航组号 | 0x00 | 0x00 | 启动自动巡航 |

## 💻 代码实现

### PHP API 层 (Gb28181Service.php)

```php
/**
 * 巡航功能完整实现
 */
class Gb28181Service 
{
    /**
     * 添加巡航点到巡航组
     * 
     * 使用示例：
     * ```php
     * // 1. 先设置3个预置位
     * $service->presetSet($deviceId, $channelId, 1);  // 入口
     * $service->presetSet($deviceId, $channelId, 2);  // 停车区A  
     * $service->presetSet($deviceId, $channelId, 3);  // 停车区B
     * 
     * // 2. 将预置位加入巡航组0
     * $service->cruiseAddPoint($deviceId, $channelId, 0, 1);
     * $service->cruiseAddPoint($deviceId, $channelId, 0, 2);
     * $service->cruiseAddPoint($deviceId, $channelId, 0, 3);
     * 
     * // 3. 设置巡航参数
     * $service->cruiseSetSpeed($deviceId, $channelId, 0, 80);    // 速度
     * $service->cruiseSetDuration($deviceId, $channelId, 0, 10); // 每点停10秒
     * 
     * // 4. 开始巡航
     * $service->cruiseStart($deviceId, $channelId, 0);
     * ```
     */
    public function cruiseAddPoint(string $deviceId, string $channelId, int $groupId, int $presetId): bool;
    public function cruiseDeletePoint(string $deviceId, string $channelId, int $groupId, int $presetId): bool;
    public function cruiseSetSpeed(string $deviceId, string $channelId, int $groupId, int $speed): bool;
    public function cruiseSetDuration(string $deviceId, string $channelId, int $groupId, int $duration): bool;
    public function cruiseStart(string $deviceId, string $channelId, int $groupId): bool;
    public function cruiseStop(string $deviceId, string $channelId): bool;
}
```

## 🏗️ 架构集成

### Master-Worker-Task 架构中的巡航

```php
// Worker 进程：处理 SIP 协议
$sipServer->onMessage(function($event) use ($gb28181) {
    // GB28181 巡航响应处理
    $gb28181->handleMessage($event);
});

// Task 进程：处理 Redis 队列的巡航命令
$sipServer->onTask(function($server, $taskId, $data) {
    if ($data['action'] === 'cruise_start') {
        // 通过管道发送给 Worker
        $server->sendToWorker([
            'type' => 'cruise_control',
            'action' => $data['action'],
            'device_id' => $data['device_id'],
            'params' => $data['params']
        ]);
    }
});

// Worker 接收 Task 的巡航命令
$sipServer->onPipeMessage(function($server, $data) use ($gb28181) {
    if ($data['type'] === 'cruise_control') {
        $gb28181->executeCruiseCommand($data);
    }
});
```

## 📊 完整使用示例

### 停车场监控巡航配置

```php
// 停车场 4 点巡航示例
class ParkingLotCruise 
{
    private Gb28181Service $gb28181;
    
    public function setupCruiseRoute(string $deviceId, string $channelId): bool 
    {
        echo "=== 停车场巡航路径配置 ===\n";
        
        // 步骤1：设置4个预置位（需要手动调整摄像头到位置后设置）
        echo "[1/7] 请手动调整摄像头到【入口位置】，然后按回车继续...\n";
        readline();
        $this->gb28181->presetSet($deviceId, $channelId, 1);
        echo "✓ 预置位1（入口）设置完成\n";
        
        echo "[2/7] 请手动调整摄像头到【停车区A】，然后按回车继续...\n";
        readline();
        $this->gb28181->presetSet($deviceId, $channelId, 2);
        echo "✓ 预置位2（停车区A）设置完成\n";
        
        echo "[3/7] 请手动调整摄像头到【停车区B】，然后按回车继续...\n";
        readline();
        $this->gb28181->presetSet($deviceId, $channelId, 3);
        echo "✓ 预置位3（停车区B）设置完成\n";
        
        echo "[4/7] 请手动调整摄像头到【出口位置】，然后按回车继续...\n";  
        readline();
        $this->gb28181->presetSet($deviceId, $channelId, 4);
        echo "✓ 预置位4（出口）设置完成\n";
        
        // 步骤2：配置巡航路径（巡航组0）
        echo "[5/7] 配置巡航路径...\n";
        $this->gb28181->cruiseAddPoint($deviceId, $channelId, 0, 1);  // 入口
        $this->gb28181->cruiseAddPoint($deviceId, $channelId, 0, 2);  // 停车区A
        $this->gb28181->cruiseAddPoint($deviceId, $channelId, 0, 3);  // 停车区B  
        $this->gb28181->cruiseAddPoint($deviceId, $channelId, 0, 4);  // 出口
        echo "✓ 巡航路径配置完成：入口→停车区A→停车区B→出口→循环\n";
        
        // 步骤3：设置巡航参数
        echo "[6/7] 设置巡航参数...\n";
        $this->gb28181->cruiseSetSpeed($deviceId, $channelId, 0, 60);    // 中等速度
        $this->gb28181->cruiseSetDuration($deviceId, $channelId, 0, 15); // 每个点停15秒
        echo "✓ 巡航参数设置完成：速度=60, 停留=15秒\n";
        
        // 步骤4：开始巡航
        echo "[7/7] 开始自动巡航...\n";
        $result = $this->gb28181->cruiseStart($deviceId, $channelId, 0);
        
        if ($result) {
            echo "🎉 停车场自动巡航已启动！\n";
            echo "摄像头将自动在 入口→停车区A→停车区B→出口 间循环监控\n";
            return true;
        } else {
            echo "❌ 巡航启动失败\n";
            return false;
        }
    }
    
    public function stopCruise(string $deviceId, string $channelId): bool
    {
        return $this->gb28181->cruiseStop($deviceId, $channelId);
    }
}
```

## ⚠️ 重要注意事项

### 1. **厂商兼容性**
- ✅ **主流支持**：海康、大华、宇视基本都支持
- ⚠️ **部分支持**：一些低端设备可能不支持
- 🔍 **验证方法**：先测试预置位，再测试巡航

### 2. **参数限制**
- **速度范围**：1-4095（实际速度受厂商保护机制限制）
- **时间范围**：1-4095秒（太短可能被设备忽略）
- **预置位数量**：每个巡航组最多255个点
- **巡航组数量**：支持0-255个不同的巡航组

### 3. **性能注意**
- **指令间隔**：相邻指令至少间隔200ms（防止丢失）
- **停留时间**：不宜过短，建议≥5秒（厂商保护）
- **巡航速度**：不宜过快，建议50-100（设备保护）

### 4. **错误处理**
```php
try {
    $result = $gb28181->cruiseStart($deviceId, $channelId, 0);
    if (!$result) {
        // 可能原因：
        // 1. 设备不支持巡航
        // 2. 巡航组内没有预置位
        // 3. 网络通信失败
        throw new Exception('巡航启动失败');
    }
} catch (Exception $e) {
    Log::error("Cruise failed: " . $e->getMessage());
}
```

## 🔗 与其他功能的配合

### 与预置位的关系
```php
// 必须先有预置位，才能配置巡航
$gb28181->presetSet($deviceId, $channelId, 1);     // 保存当前位置为预置位1
$gb28181->presetCall($deviceId, $channelId, 1);    // 快速跳转到预置位1
$gb28181->cruiseAddPoint($deviceId, $channelId, 0, 1);  // 将预置位1加入巡航
```

### 与报警联动
```php  
// 触发报警时，停止巡航并跳转到报警位置
$gb28181->onAlarm(function($alarmEvent) use ($gb28181) {
    $deviceId = $alarmEvent->getDeviceId();
    $channelId = $alarmEvent->getChannelId();
    
    // 停止当前巡航
    $gb28181->cruiseStop($deviceId, $channelId);
    
    // 跳转到预设的报警监控位置
    $gb28181->presetCall($deviceId, $channelId, 99);  // 预置位99为报警监控点
});
```

### 与录像联动
```php
// 巡航过程中自动录像
$gb28181->onCruisePointReached(function($point) use ($gb28181) {
    // 到达关键监控点时开始录像
    if (in_array($point['preset_id'], [2, 3])) {  // 停车区需要录像
        $gb28181->startRecord($point['device_id'], $point['channel_id']);
    }
});
```

## 📈 性能优化建议

### 1. **批量设置优化**
```php
// 错误方式：连续发送（可能导致指令丢失）
$gb28181->cruiseAddPoint($deviceId, $channelId, 0, 1);
$gb28181->cruiseAddPoint($deviceId, $channelId, 0, 2);  // 可能丢失
$gb28181->cruiseAddPoint($deviceId, $channelId, 0, 3);  // 可能丢失

// 正确方式：添加延迟
foreach ([1, 2, 3, 4] as $presetId) {
    $gb28181->cruiseAddPoint($deviceId, $channelId, 0, $presetId);
    usleep(300000);  // 300ms 延迟
}
```

### 2. **状态检查**
```php
// 启动前检查设备状态
$deviceStatus = $gb28181->queryDeviceStatus($deviceId);
if ($deviceStatus['online'] && $deviceStatus['ptz_enabled']) {
    $gb28181->cruiseStart($deviceId, $channelId, 0);
}
```
