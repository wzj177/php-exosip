## ❌ 缺失功能分析

### 1. 主动发起 SUBSCRIBE

**问题**: 当前只能**接收**设备的订阅请求，无法**主动向设备发起订阅**。

**缺失代码位置**:

- `Gb28181Client.php` - 需要添加 `subscribeMobilePosition()` 和 `unsubscribeMobilePosition()` 方法
- `CommandDispatcher.php` - 需要添加 `subscribe_mobile_position` action 处理
- `QuerySender.php` - 需要添加 `sendSubscribe()` 方法

**需要实现的方法**:

```php
// QuerySender.php
public function sendSubscribe(
    string $deviceUri, 
    string $deviceId, 
    string $eventType, 
    int $expires = 3600,
    ?int $interval = null
): bool {
    // 构建 SUBSCRIBE 请求
    // Event: presence / Catalog / Alarm / DeviceStatus
    // Expires: 订阅时长
    // Body: 可选，包含 Interval 等参数
}
```

```php
// Gb28181Client.php
public function subscribeMobilePosition(string $deviceId, int $expires = 3600, ?int $interval = null): bool
{
    return $this->sendCommand($deviceId, 'subscribe_mobile_position', [
        'expires' => $expires,
        'interval' => $interval
    ]);
}

public function unsubscribeMobilePosition(string $deviceId): bool
{
    return $this->sendCommand($deviceId, 'subscribe_mobile_position', [
        'expires' => 0  // Expires=0 表示取消订阅
    ]);
}
```

### 2. Catalog 目录订阅

**场景**: 设备通道增删改时自动通知平台，无需轮询。

**需要实现**:

1. `handleSubscribe()` 添加 `Event: Catalog` 分支
2. `handleCatalogNotify()` 处理目录变更通知
3. `CatalogSubscribeCommand.php` 解析订阅通知内容

### 3. Alarm 报警订阅

**场景**: 设备报警事件实时推送。

**需要实现**:

1. `handleSubscribe()` 添加 `Event: Alarm` 分支
2. `handleAlarmNotify()` 处理报警订阅通知
3. 区分 MESSAGE 报警上报和 SUBSCRIBE/NOTIFY 报警订阅

### 4. 订阅自动续期

**场景**: 订阅即将过期时自动发送 SUBSCRIBE 刷新。

**需要实现**:

```php
// GB28181Handler.php tick() 方法中添加
private function checkSubscriptionExpiry(): void
{
    foreach ($this->deviceManager->getAllDevices() as $device) {
        foreach ($device['subscriptions'] ?? [] as $type => $subscription) {
            $expireTime = $subscription['expire_time'] ?? 0;
            $renewBefore = 60; // 提前60秒续期
            
            if (time() >= $expireTime - $renewBefore) {
                $this->renewSubscription($device['device_id'], $type, $subscription);
            }
        }
    }
}
```

## 📋 实现优先级建议

| 优先级 | 功能 | 原因 |
|--------|------|------|
| P0 (紧急) | **主动发起 SUBSCRIBE** | 当前只能被动接收，无法主动订阅设备 |
| P1 (高) | **Catalog 目录订阅** | 避免轮询查询目录，提升效率 |
| P1 (高) | **Alarm 报警订阅** | 报警事件实时性要求高 |
| P2 (中) | **订阅自动续期** | 防止订阅过期中断 |
| P3 (低) | **DeviceStatus 订阅** | 可以通过心跳超时检测代替 |
| P3 (低) | **PTZControl (2022)** | 非标准核心事件，可选 |
