## 📋 问题描述

**原始问题**：
> 我的 exosip 插件在处理设备指令控制响应这块儿少了点功能：无法正确判断设备对指令执行成功的响应，从而无法 post task 到 hook api 去更新一些业务逻辑。

**问题分析**：
1. 平台发送 PTZ 控制指令（MESSAGE DeviceControl）
2. 设备响应 `SIP/2.0 200 OK`（Content-Length: 0）
3. ❌ 代码没有处理这个 200 OK 响应
4. ❌ Hook API 无法收到 `command_confirmed` 通知

```php
public function handleResponse(\SipEvent $event): void
{
    $code = $event->getCode();
    $type = $event->getType();
    $callId = $event->getCallId();
    
    if ($code == 200) {
        // INVITE 200 OK (含 SDP)
        if ($type == EXOSIP_CALL_ANSWERED) {
            $this->handleInviteResponse($event);
        }
        // MESSAGE 200 OK (空 body) ← 新增
        elseif ($type == EXOSIP_MESSAGE_ANSWERED) {
            $this->handleMessageResponse($event);
        }
    }
}
```

**功能**：识别 `EXOSIP_MESSAGE_ANSWERED` 事件并分发到正确的处理器

#### ✅ handleMessageResponse() - 核心处理逻辑

**位置**: 第 1234 行

```php
private function handleMessageResponse(\SipEvent $event): void
{
    $code = $event->getCode();
    $callId = $event->getCallId();
    $toUri = $event->getToUri();
    $deviceId = $this->extractDeviceId($toUri);
    
    // 从 CSeq 提取序列号
    $cseqHeader = $event->getHeader('CSeq');
    $cseqNumber = null;
    $method = 'MESSAGE';
    
    if ($cseqHeader && preg_match('/(\d+)\s+(\w+)/', $cseqHeader, $matches)) {
        $cseqNumber = (int)$matches[1];
        $method = $matches[2];
    }
    
    $this->log("收到 MESSAGE 200 OK: 设备 {$deviceId}, Call-ID: {$callId}, CSeq: {$cseqNumber}");
    
    // 发送到 Hook API
    $this->postTask('command_confirmed', [
        'device_id' => $deviceId,
        'call_id' => $callId,
        'cseq' => $cseqNumber,
        'status_code' => $code,
        'method' => $method,
        'timestamp' => time(),
    ]);
}
```

**关键功能**：
- ✅ 提取设备 ID（从 To URI）
- ✅ 提取 Call-ID（用于关联原始请求）
- ✅ 解析 CSeq 头（格式: "20 MESSAGE" → 提取数字 20）
- ✅ 调用 `postTask('command_confirmed')` 发送到 Hook API

```php
private function handleInviteResponse(\SipEvent $event): void
{
    $callId = $event->getCallId();
    $dialogId = $event->getDialogId();
    $deviceId = $this->extractDeviceId($event->getFromUri());
    
    // 解析设备 SDP
    $sdp = $event->getSdp();
    $deviceSsrc = $sdp['gb28181']['ssrc'] ?? null;
    
    // 发送 ACK
    $this->sipServer->sendAck($dialogId);
    
    // 通知业务系统
    $this->postTask('media_ready', [
        'device_id' => $deviceId,
        'call_id' => $callId,
        'device_ssrc' => $deviceSsrc,
        // ...
    ]);
}
```

**功能**：处理 INVITE 200 OK（含 SDP），提取 SSRC 用于 ZLM 流关联
