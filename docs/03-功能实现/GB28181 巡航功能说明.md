# GB28181 巡航功能说明

## 📖 什么是巡航功能

**巡航（Cruise）** 是云台摄像头的一种自动控制功能，让摄像头**自动在多个预置位之间循环移动**，无需人工操作。

## 🔄 巡航 vs 预置位的关系

### 预置位（Preset）
- **单点定位**：保存一个固定的云台位置
- **手动切换**：需要人工调用
- **用途**：快速切换到重要位置

### 巡航（Cruise）
- **多点巡视**：自动在多个预置位之间移动
- **自动循环**：无需人工干预
- **用途**：自动监控多个区域

## 🎯 工作原理

```
工作流程：
┌────────────────────────────────────────────────────┐
│ 1. 设置预置位                                        │
│    ├─ 预置位1：大门入口                              │
│    ├─ 预置位2：停车区A                              │
│    ├─ 预置位3：停车区B                              │
│    └─ 预置位4：后门出口                              │
│                                                      │
│ 2. 配置巡航路径                                      │
│    └─ 巡航路径1：预置位1→2→3→4→1（循环）            │
│                                                      │
│ 3. 启动巡航                                          │
│    └─ 摄像头自动移动，每个位置停留N秒                │
└────────────────────────────────────────────────────┘
```

## 📋 GB28181 巡航命令

### 命令格式（XML）

```xml
<?xml version="1.0" encoding="GB2312"?>
<Control>
  <CmdType>DeviceControl</CmdType>
  <SN>123456</SN>
  <DeviceID>34020000001320000001</DeviceID>
  
  <!-- 选项1：使用PTZCmd（推荐） -->
  <PTZCmd>A50F018500xx00yy</PTZCmd>  <!-- 0x85=开始巡航, 0x86=停止巡航 -->
  
  <!-- 选项2：使用CruiseGroup（设备支持的话） -->
  <CruiseGroup>
    <Command>Start</Command>  <!-- Start/Stop -->
    <GroupID>1</GroupID>       <!-- 巡航路径ID: 1-255 -->
    <Speed>5</Speed>           <!-- 巡航速度 -->
    <StayTime>10</StayTime>    <!-- 每个点停留时间(秒) -->
  </CruiseGroup>
</Control>
```

### PTZ 命令码（方式1 - 最常用）

| 命令码 | 功能 | 格式 | 说明 |
|--------|------|------|------|
| `0x85` | 开始巡航 | `A50F018500[路径ID]00[校验]` | 启动指定路径巡航 |
| `0x86` | 停止巡航 | `A50F018600000000[校验]` | 停止当前巡航 |
| `0x87` | 设置巡航点 | `A50F0187[点号][预置位ID]00[校验]` | 配置巡航路径 |
| `0x88` | 删除巡航点 | `A50F0188[点号]0000[校验]` | 从路径中删除点 |

### 扫描（Scan）命令码（相关功能）

| 命令码 | 功能 | 说明 |
|--------|------|------|
| `0x89` | 开始扫描 | 在左右边界之间来回扫描 |
| `0x8A` | 停止扫描 | 停止扫描运动 |
| `0x8B` | 设置左边界 | 保存当前位置为左边界 |
| `0x8C` | 设置右边界 | 保存当前位置为右边界 |

## 💻 实现示例

### PHP 实现（需要添加）

```php
// 在 Gb28181Service.php 中添加巡航方法

/**
 * 开始巡航
 * 
 * @param string $deviceId 设备ID
 * @param string $channelId 通道ID
 * @param int $cruiseId 巡航路径ID (1-255)
 * @param int $speed 巡航速度 (1-255)
 * @return bool
 */
public function startCruise(
    string $deviceId,
    string $channelId,
    int $cruiseId = 1,
    int $speed = 5
): bool {
    // 构建 PTZ 命令: A5 0F 01 85 00 [cruiseId] 00 [checksum]
    $cmdCode = 0x85;
    $checksum = (0xA5 + 0x0F + 0x01 + $cmdCode + 0x00 + $cruiseId + 0x00) % 0x100;
    $ptzCmd = sprintf("A50F01%02X00%02X00%02X", $cmdCode, $cruiseId, $checksum);
    
    return $this->sendPtzCommand($deviceId, $channelId, $ptzCmd);
}

/**
 * 停止巡航
 */
public function stopCruise(
    string $deviceId,
    string $channelId
): bool {
    // PTZ 命令: A5 0F 01 86 00 00 00 [checksum]
    $cmdCode = 0x86;
    $checksum = (0xA5 + 0x0F + 0x01 + $cmdCode) % 0x100;
    $ptzCmd = sprintf("A50F01%02X000000%02X", $cmdCode, $checksum);
    
    return $this->sendPtzCommand($deviceId, $channelId, $ptzCmd);
}

/**
 * 添加巡航点
 * 
 * @param string $deviceId 设备ID
 * @param string $channelId 通道ID
 * @param int $cruiseId 巡航路径ID
 * @param int $pointIndex 巡航点序号 (1-255)
 * @param int $presetId 预置位ID
 * @param int $stayTime 停留时间(秒)
 * @return bool
 */
public function addCruisePoint(
    string $deviceId,
    string $channelId,
    int $cruiseId,
    int $pointIndex,
    int $presetId,
    int $stayTime = 10
): bool {
    // 方式1: 通过PTZ命令
    // A5 0F 01 87 [pointIndex] [presetId] [stayTime] [checksum]
    $cmdCode = 0x87;
    $checksum = (0xA5 + 0x0F + 0x01 + $cmdCode + $pointIndex + $presetId + $stayTime) % 0x100;
    $ptzCmd = sprintf("A50F01%02X%02X%02X%02X%02X", 
        $cmdCode, $pointIndex, $presetId, $stayTime, $checksum);
    
    return $this->sendPtzCommand($deviceId, $channelId, $ptzCmd);
}
```

### 使用示例

```php
$service = new Gb28181Service($bfw);

$deviceId = '34020000001320000001';
$channelId = '34020000001320000001';

// 步骤1: 先设置预置位
$service->presetSet($deviceId, $channelId, 1);  // 大门
sleep(2);
// ... 移动云台到停车区A ...
$service->presetSet($deviceId, $channelId, 2);  // 停车区A
sleep(2);
// ... 移动云台到停车区B ...
$service->presetSet($deviceId, $channelId, 3);  // 停车区B
sleep(2);
// ... 移动云台到后门 ...
$service->presetSet($deviceId, $channelId, 4);  // 后门

// 步骤2: 配置巡航路径（如果设备支持）
$cruiseId = 1;  // 巡航路径1
$service->addCruisePoint($deviceId, $channelId, $cruiseId, 1, 1, 10);  // 点1→预置位1，停留10秒
$service->addCruisePoint($deviceId, $channelId, $cruiseId, 2, 2, 10);  // 点2→预置位2，停留10秒
$service->addCruisePoint($deviceId, $channelId, $cruiseId, 3, 3, 10);  // 点3→预置位3，停留10秒
$service->addCruisePoint($deviceId, $channelId, $cruiseId, 4, 4, 10);  // 点4→预置位4，停留10秒

// 步骤3: 启动巡航
$service->startCruise($deviceId, $channelId, $cruiseId);

// 需要时停止
// $service->stopCruise($deviceId, $channelId);
```

## ⚠️ 设备兼容性

### 支持情况

| 厂商 | 巡航支持 | 配置方式 | 说明 |
|------|---------|---------|------|
| **海康威视** | ✅ 支持 | PTZ命令 或 Web配置 | 需要在NVR/摄像头Web界面预先配置巡航路径 |
| **大华** | ✅ 支持 | PTZ命令 或 Web配置 | 同海康 |
| **宇视** | ✅ 支持 | PTZ命令 | 大部分型号支持 |
| **低端设备** | ❌ 不支持 | - | 可能只支持预置位，不支持巡航 |

### 两种配置方式

#### 方式1：Web 界面配置（推荐）
1. 登录摄像头/NVR Web 管理界面
2. 找到"云台配置" → "巡航设置"
3. 配置巡航路径（选择预置位、停留时间）
4. 通过 GB28181 命令启动/停止巡航

#### 方式2：PTZ 命令配置
- 通过 `0x87` 命令添加巡航点
- 某些设备可能不支持，返回失败

## 🆚 巡航 vs 扫描的区别

| 特性 | 巡航 (Cruise) | 扫描 (Scan) |
|------|--------------|------------|
| **运动方式** | 跳跃式（预置位→预置位） | 连续扫动（左边界→右边界） |
| **配置** | 需要设置多个预置位 | 只需设置左右边界 |
| **速度** | 每个点停留固定时间 | 匀速或变速扫描 |
| **应用场景** | 监控多个分散区域 | 监控连续区域（如走廊） |
| **命令码** | 0x85/0x86 | 0x89/0x8A |

## 🚀 实现建议

### 阶段1：基础巡航（推荐先实现）
```php
// 只实现启动/停止，巡航路径在设备Web界面配置

- 实现简单（只需两个命令）

$service->startCruise($deviceId, $channelId, 1);
```

**适用于**：
- 需要动态配置巡航路径
- 设备支持通过命令配置

## 📝 总结

### ✅ 是的，巡航是和预置位一起使用的

1. **依赖关系**：巡航必须先设置预置位
2. **配置方式**：通常在设备Web界面配置巡航路径
3. **命令控制**：通过GB28181命令启动/停止巡航
4. **应用价值**：适合需要自动监控多个区域的场景

### 🎯 是否需要实现

**建议实现** 如果：
- ✅ 你的设备支持巡航功能
- ✅ 有自动监控多个区域的需求
- ✅ 想减少人工操作

**可以不实现** 如果：
- ❌ 设备不支持巡航
- ❌ 只需要固定监控某个位置
- ❌ 通过手动调用预置位就够用
