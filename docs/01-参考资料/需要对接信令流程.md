# GB28181 SIP/SDP 数据报文格式文档

## 1. 概述

本文档详细描述了 GB28181 协议中使用的 SIP 和 SDP 数据报文格式。GB28181 是中国国家标准，用于视频监控设备与平台之间的信令交互和媒体传输。

## 2. SIP 报文格式

### 2.1 REGISTER 注册请求

客户端向服务器注册设备信息：

```
REGISTER sip:34020000002000000001@192.168.1.100:5060 SIP/2.0
Via: SIP/2.0/UDP 192.168.1.101:5060;rport;branch=z9hG4bK385920994
From: <sip:34020000001320000001@192.168.1.100:5060>;tag=1903983385
To: <sip:34020000001320000001@192.168.1.100:5060>
Call-ID: 1398183919
CSeq: 1 REGISTER
Contact: <sip:34020000001320000001@192.168.1.101:5060>
Max-Forwards: 70
User-Agent: EasyGBD
Expires: 3600
Content-Length: 0
```

### 2.2 REGISTER 注册响应

服务器对客户端注册请求的响应：

```
SIP/2.0 200 OK
Via: SIP/2.0/UDP 192.168.1.101:5060;rport=5060;received=192.168.1.101;branch=z9hG4bK385920994

To: <sip:34020000001320000001@192.168.1.100:5060>;tag=1d81453479988c330857493223995372
Call-ID: 1398183919
CSeq: 1 REGISTER
Contact: <sip:34020000001320000001@192.168.1.101:5060>
Expires: 3600
User-Agent: EasyGBS
Content-Length: 0
```

## 3. SDP 报文格式

### 3.1 INVITE 邀请请求（开始实时视频）

```
INVITE sip:34020000001320000001@192.168.1.101:5060 SIP/2.0
Via: SIP/2.0/UDP 192.168.1.100:5060;rport;branch=z9hG4bK192837465
From: <sip:34020000002000000001@192.168.1.100:5060>;tag=192837465
To: <sip:34020000001320000001@192.168.1.101:5060>
Call-ID: 5647382910
CSeq: 30 INVITE
Contact: <sip:34020000002000000001@192.168.1.100:5060>
Max-Forwards: 70
Subject: 34020000001320000001:34020000001320000001,34020000002000000001:0
Content-Type: application/sdp
User-Agent: EasyGBS
Content-Length: xxx

v=0
o=34020000002000000001 0 0 IN IP4 192.168.1.100
s=Play
c=IN IP4 192.168.1.100
t=0 0
m=video 9000 RTP/AVP 96 98 97
a=recvonly
a=rtpmap:96 PS/90000
a=rtpmap:98 H264/90000
a=rtpmap:97 MPEG4/90000
y=0100000001
f=
```

## 4. SDP 参数说明

### 4.1 SDP 字段含义

- `v=0`: 协议版本，通常为0
- `o=<username> <session id> <version> <network type> <address type> <address>`: 会话发起者信息
- `s=<session name>`: 会话名称
- `c=<network type> <address type> <connection address>`: 连接信息
- `t=<start time> <stop time>`: 会话时间
- `m=<media> <port> <transport> <fmt list>`: 媒体描述
- `a=<attribute>`: 媒体属性
- `y=<ssrc>`: 同步源标识符
- `f=<config>`: 媒体配置参数

### 4.2 媒体类型

- `video`: 视频流
- `audio`: 音频流

### 4.3 传输协议

- `RTP/AVP`: RTP Audio Visual Profile
- `RTP/SAVP`: Secure RTP

### 4.4 媒体格式

- `96`: PS封装(H264)
- `98`: H264裸流
- `97`: MPEG4
- `8`: PCMA(G.711A)
- `0`: PCMU(G.711U)
- `97`: AAC

## 5. 常见 GB28181 操作对应的 SIP/SDP 报文

### 5.1 实时视频点播

1. 客户端发送 INVITE 请求
2. 设备回复 200 OK
3. 客户端发送 ACK 确认
4. 开始 RTP 视频流传输
5. 客户端发送 BYE 结束
6. 设备回复 200 OK

### 5.2 实时音频对讲

1. 客户端发送 INVITE 请求（包含音频媒体描述）
2. 设备回复 200 OK
3. 客户端发送 ACK 确认
4. 开始 RTP 音频流传输
5. 客户端发送 BYE 结束
6. 设备回复 200 OK

### 5.3 设备目录查询

1. 客户端发送 MESSAGE 请求（包含目录查询XML）
2. 设备回复 200 OK（包含设备列表XML）

### 5.4 设备状态订阅

1. 客户端发送 SUBSCRIBE 请求
2. 设备回复 200 OK
3. 设备定期发送 NOTIFY 通知
4. 客户端回复 200 OK

### 5.5 录像文件查询

1. 客户端发送 MESSAGE 请求（包含录像查询XML）
2. 设备回复 200 OK（包含录像文件列表XML）

### 5.6 录像回放

1. 客户端发送 INVITE 请求（包含录像文件信息）
2. 设备回复 200 OK
3. 客户端发送 ACK 确认
4. 开始 RTP 录像流传输
5. 客户端发送 BYE 结束
6. 设备回复 200 OK

## 6. 注意事项

1. 所有 XML 内容应使用 GB2312 编码
2. SIP 消息头字段大小写不敏感
3. SDP 中的媒体端口是接收端口
4. SSRC (y字段) 用于同步媒体流
5. f字段用于媒体参数配置
6. 所有时间戳使用 UTC 时间
