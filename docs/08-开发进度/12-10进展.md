### 🔍 IP地址选择逻辑

**优先级顺序**:
1. **配置的 `public_ip`** (推荐) - 适用于固定公网IP或NAT环境
2. **自动检测** (listen_addr=0.0.0.0时) - 获取第一个非回环IP
3. **监听IP** (listen_addr≠0.0.0.0时) - 使用配置的监听地址

**使用场景**:
- **公网服务器**: `public_ip` = 公网IP
- **NAT后的服务器**: `public_ip` = NAT映射后的公网IP
- **局域网**: `public_ip` = 局域网IP (如 `10.20.2.8`)
- **多网卡**: `public_ip` = 指定网卡IP

## 七、技术要点总结

### GB28181 INVITE 流程关键点
1. **From URI**: `sip:{server_id}@{realm}` (平台标识)
2. **To URI**: `sip:{channel_id}@{device_ip}:{device_port}` (通道标识)
3. **Subject**: `{channel_id}:{channel_id},{server_id}:0` (GB28181扩展头)
4. **SDP**: 必须包含正确的 IP、端口、SSRC、传输协议

### eXosip call_id 重要说明
- `call_id` 从 **0 开始递增**
- `call_id >= 0` 表示成功
- `call_id < 0` 表示失败
- **不能用 `!$call_id` 或 `empty($call_id)` 判断**
- 必须用 `=== false` 严格判断

### TCP 模式实现要点
- RFC 4145: TCP-Based Media Transport in SDP
- `TCP/RTP/AVP` 协议标识
- `a=setup:passive` - 被动模式(服务器等待连接)
- `a=setup:active` - 主动模式(服务器主动连接)
- `a=connection:new` - 每个流创建新连接

### ZLM Stream ID 管理要点
- **Stream ID 格式**: `{deviceId}_{channelId}`
- **作用**: 在 ZLM 中标识和管理 RTP 流,避免使用抽象的 SSRC
- **openRtpServer**: 创建指定 stream_id 的 RTP 接收端口
- **自动释放机制**: 如果端口一直没收到流或解析不出流,ZLM 会自动关闭和释放
- **管理接口**:
  - `openRtpServer(streamId)` - 创建端口
  - `closeRtpServer(streamId)` - 关闭端口
  - `updateRtpServerSsrc(streamId, ssrc)` - 更新 SSRC (设备响应 200 OK 后调用)
